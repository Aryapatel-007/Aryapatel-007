### Hi, I'm Arya 👋

I build software that keeps working when the network doesn't: **local-first AI tools**
that run on your own GPU, **offline-first ERP and POS systems** running in real restaurants
and factories, and fixes that ship in **open-source projects** used by millions.

| Project | What it does | Stack |

| **[Argus](https://github.com/Aryapatel-007/argus)** | Watches the pages you care about, works out what really changed, and drafts messages that never leave your machine until you approve them. Re-plans at run time, picks models around one GPU's VRAM, resumes after a crash. | Python · Ollama · SQLite · MCP |
| **[Caveman Code](https://github.com/Aryapatel-007/caveman-code)** | A local AI coding agent for VS Code. Several models propose edits, each is compiled in a shadow workspace, and your own toolchain picks the winner. | TypeScript · VS Code · Ollama |

#### 🧭 How I build

- **Verify, don't trust.** Model output passes through compilers, validators and tests before anyone sees it.
- **Local-first.** Your data stays on your machine, and the café's billing works when the WiFi doesn't.
- **Safe by structure.** Approval gates, append-only ledgers and crash-safe checkpoints are part of the design, not reminders in a doc.
